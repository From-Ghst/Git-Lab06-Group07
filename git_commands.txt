Git Commands Used in This Lab:

1. git init_
   Initializes a new local Git repository.

2. git status_
   Displays the current status of the working directory and staging area.

3. git add git_commands.txt_
   Stages git_commands.txt so it can be included in the next commit.

4. git add ._
   Stages all changed and untracked files in the current directory.

5. git commit -m "Add Git commands documentation"_
   Saves the staged changes as a commit with a descriptive message.

6. git remote -v_
   Displays the remote repository URLs connected to the local repository.

7. git push_
   Uploads local commits to the connected remote repository, such as GitHub.

8. git pull_
   Downloads and integrates the latest changes from the remote repository.

9. git log_
   Displays the commit history of the repository.

10. git branch_
    Lists the local branches in the repository.
